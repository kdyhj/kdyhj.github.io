# 오프라인성경 · OfflineBible

인터넷 연결 없이 성경을 읽고 검색할 수 있는 앱입니다.
한국어 새찬송·구찬송 버전과 영어 버전을 제공합니다.

## 주요 기능
- 성경 읽기와 검색
- 대조성경과 버전별 비교
- 하이라이트, 북마크, 성경 읽기표
- 메모와 성경주석
- 설정 및 데이터 백업·복원

한국어 버전에서는 찬송 악보와 가사, 교독문도 제공합니다.
사용자 음원과 CCM 파일은 별도로 준비해야 합니다.
